# Docker Text Extractor

A simple document text extraction service built with **FastAPI** and **Apache Tika**, fully containerized using **Docker**.

The service exposes an API endpoint that accepts document uploads and returns extracted text.

---

## Features

- Extract text from PDFs, DOCX, TXT, and other formats
- Powered by Apache Tika
- FastAPI REST API
- Dockerized microservice architecture
- Easy local testing with Python script
